# Amazon Homepage Clone

A recreation of the Amazon homepage built from scratch with HTML and CSS, as practice in translating a complex, dense real-world layout into clean markup and styles.

---

## ✨ What's in it

- **Header.** Logo, delivery location, category dropdown, search bar, account, returns and orders, and cart
- **Navigation bar.** All menu, Today's Deals, Customer Service, Registry, Gift Cards and Sell
- **Hero and shopping cards.** A grid of category cards (Electronics, Laptops, Smartwatches and more) with "Shop now" links
- **Footer.** A multi-column footer with links

## 🛠 Built with

HTML · CSS (Flexbox)

## 🚀 Run locally

Open `index.html` in a browser. No build step needed.

## 🧠 What I practiced

Breaking a busy commercial page into reusable sections, matching spacing and visual hierarchy closely, and keeping the CSS organized by component.
